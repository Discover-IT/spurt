# Sportclub De Spurt

Dit is de oude website van Sportclub De Spurt, de klant van de Dag 2-opdracht van Discover IT.
Maak er met **Use this template** een eigen repository van, en zet daarna onder *Settings → Pages* GitHub Pages aan vanaf de branch `main`.
Je site staat dan op `https://<gebruikersnaam>.github.io/<repository>/`.
